Setup

Get your project running in about three minutes. You need an account, the CLI installed, and a modern browser.

1 Create your account

Go to yourdomain.com and click Continue with OAuth. We use OAuth so there is no separate password to manage. Authorize the app when prompted and you'll be returned to the dashboard.

We never see your credentials. OAuth only shares your username, user ID, and avatar with our system.

2 Install the CLI

Run the install command from your terminal. After installing, restart your shell so the yourdocs command is available on your PATH.

bash
# Install globally via npm npm install -g @yourdocs/cli # Or use Homebrew (macOS) brew install yourdocs

3 Authenticate the CLI

The CLI authenticates automatically using the account you are signed into on the dashboard. There is no API key to paste. If your terminal shows a green status indicator, you are connected.

bash
yourdocs auth login # Opens browser for OAuth flow ✓ Authenticated as yourname@example.com
You must be logged in with the same account on both the web app and the CLI. Mismatched accounts is the most common setup issue.

4 Enable API access

Your project needs API access enabled. Open your project settings and toggle Allow API Requests on. This is per-project, so repeat this step for every project you want the CLI to work with.

If API access is off, the CLI will appear connected but no changes will reach your project.

5 Send your first request

Head back to the dashboard and run your first command. The system will read your project, plan the change, and apply it live.

bash
yourdocs start --project my-app ✓ Connected to project "my-app" ✓ Watching for changes... # Ask the AI a question > Add a login button to the header

What gets synced

The CLI watches the directories where your app code actually lives. This includes src/, components/, pages/, api/, styles/, and public/.

The .env file and secrets/ folder are intentionally never synced so that private keys and credentials stay out of the AI context.

Troubleshooting

If the CLI shows as offline, double-check that you are logged into the same account on both the web app and the CLI, and that API access is enabled for your project. See the Troubleshooting Hub for more details.
